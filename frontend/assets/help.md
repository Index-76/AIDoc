# AIDoc 智能文档处理平台 - 使用帮助

欢迎使用 AIDoc 智能文档处理平台！本平台结合了AI对话与文档管理功能，帮助您高效处理各类文档。以下将详细介绍界面的各个部分及其使用方法。

## 界面概览

主页分为左右两大区域：
- **左侧**：四个文件管理区域（等待、读取、模板、结果）
- **右侧**：AI聊天对话区域
- **顶部工具栏**：提供全局操作按钮

## 左侧文件区域

左侧由上下两排共四个文件卡片组成，每个卡片对应一类文件，支持上传、下载、删除、移动、重命名等操作（具体操作方式取决于各文件区域的实现，通常点击文件可预览或下载，点击上传按钮可添加文件）。

### 等待区域
- **用途**：存放待处理的原始文档。您可以将需要AI处理的文档上传至此，AI会基于这些文件的内容进行问答或处理。
- **操作**：上传新文件、查看文件列表、删除文件。

### 读取区域
- **用途**：显示已成功读取并解析的文档内容。AI在处理过程中会将读取后的文件移至此区域，便于您确认文件已被正确处理。
- **操作**：查看已读取的文件列表，下载或删除文件。

### 模板区域
- **用途**：存放文档处理模板（例如表格模板、格式模板等）。当您需要使用特定模板进行格式转换或智能填表时，可将模板文件放在此处。
- **操作**：上传模板、选择模板应用到当前任务。

### 结果区域
- **用途**：展示AI处理完成后的结果文件（如转换后的文档、填好的表格、修改后的文件）。当AI完成格式转换、智能填表或智能修改操作后，生成的文件会自动出现在此区域。
- **操作**：下载结果文件、删除文件。

**提示**：所有文件区域支持实时刷新，您可以点击顶部工具栏的“刷新工作区”按钮更新文件列表，或使用“清除文件缓存”按钮清理临时文件缓存。

## 右侧聊天区域

右侧是您与AI智能助手进行对话的主要区域。

### 聊天消息列表
- 显示您与AI的对话历史。您的消息显示在右侧（用户），AI的回复显示在左侧（AI），系统提示消息（如“已执行XX操作”）会以特殊样式显示。
- 当AI正在处理时，列表底部会显示一个带状态提示的加载指示器（如“正在使用目录查看工具...”），让您了解当前处理进度。

### 输入框与发送
- 底部输入框：在此输入您的问题或指令（例如“总结xx文档”、“将文件转换为PDF”）。
- 发送按钮（纸飞机图标）：点击发送消息，或直接按回车键发送。
- 输入框会自动获得焦点，方便连续对话。

**AI处理流程**：
1. 您发送消息后，AI会判断是否需要调用工具（如目录查看、内容总结、格式转换、智能填表、智能修改）。
2. 若调用工具，聊天区域会显示工具执行状态（例如“正在使用内容总结工具...”）。
3. 工具执行完成后，AI会回复最终结果，同时系统会提示“已执行XX操作”。
4. 如果操作涉及文件生成（格式转换、智能填表、智能修改），结果文件会自动刷新到左侧的“结果”区域。

## 顶部工具栏

顶部工具栏提供了一系列快捷操作按钮，鼠标悬停可查看提示。

| 按钮 | 功能说明 |
|------|----------|
| 刷新 | 手动刷新所有文件区域（等待、读取、模板、结果）的文件列表，确保显示最新状态。 |
| 清除缓存 | 清除所有文件区域的本地缓存，可用于解决文件显示异常或释放空间。 |
| 新建对话 | 创建一个新的空白对话。新对话会立即显示在右侧，您可以开始新的问答。 |
| 历史 | 查看和管理历史对话。点击后弹出菜单，列出所有历史对话（按时间倒序）。可切换至其他对话，或将鼠标悬停在某项上出现删除按钮以删除该对话。 |
| 配置 | 打开配置对话框，设置AI模型相关参数（如API密钥、模型名称、接口地址）。修改后点击“保存”生效。 |
| 帮助 | 打开此帮助文档。 |
| 登出 | 退出当前账号，返回登录页面。 |

### 对话历史管理
- 点击“历史”按钮，弹出菜单显示所有对话列表（对话1、对话2...）。
- **切换对话**：点击菜单中的任一对话项，右侧聊天区会立即加载该对话的历史消息，并切换到该对话。
- **删除对话**：将鼠标悬停在菜单项上，右侧会出现红色关闭图标，点击即可删除对应对话。如果删除的是当前对话，系统会自动切换到最近的另一个对话或创建新对话。

## 配置设置

在配置对话框中，您可以修改以下参数：
- **SiliconFlow API Key**：您的API密钥，用于调用AI模型。
- **SiliconFlow Base URL**：API接口地址，默认指向SiliconFlow服务。
- **聊天模型名称**：用于对话的模型（如 `deepseek-ai/DeepSeek-V3.2`）。
- **决策模型名称**：用于工具调用决策的模型（如 `Qwen/Qwen2.5-7B-Instruct`）。
- **分析模型名称**：用于文档内容分析的模型。

修改后点击“保存”立即生效。

## 常见问题

**Q：如何上传文件到左侧区域？**  
A：每个文件区域内部通常有上传按钮，点击即可选择本地文件上传。具体实现可能因版本而异，请参考区域内的提示。

**Q：AI处理结果文件在哪里查看？**  
A：处理完成后，结果文件会自动出现在左侧“结果”区域，您可以点击文件进行下载。

**Q：如何知道AI当前正在做什么？**  
A：聊天区域底部会显示状态提示，例如“正在使用内容总结工具...”，让您了解当前执行的操作。

**Q：为什么新建对话后，之前的对话不见了？**  
A：之前的对话并未丢失，您可以通过点击顶部工具栏的“历史”按钮，在弹出的菜单中查看并切换回之前的对话。

**Q：清除文件缓存会删除我的文件吗？**  
A：不会，清除缓存仅删除临时存储的文件信息，不会影响实际文件。下次刷新时会重新加载。
